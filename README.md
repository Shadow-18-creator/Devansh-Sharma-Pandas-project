# 🚢 Titanic Dataset Cleaner & Exploratory Data Analysis (EDA)

A Python data cleaning and exploratory analysis pipeline built with **Pandas**. This project takes the raw Titanic passenger dataset, standardizes and cleans missing or inconsistent records, engineers new features, exports a clean CSV file, and runs demographic and behavioral survival analyses.

---

## 📋 Features & Pipeline Overview

### 1. Data Inspection & Cleaning
* **Initial Audit:** Inspects dataset dimensions (`shape`), column names, data types (`dtypes`), missing values (`isna`), and duplicate counts before processing.
* **String & Schema Standardization:** Drops stray index columns (`Unnamed: 0`), strips whitespace from column headers and text fields, and removes duplicate rows.
* **Missing Value Imputation:**
  * `Age`: Filled with the **median** age to prevent distortion from outliers.
  * `Embarked`: Filled with the **mode** (most frequent port of embarkation).
  * `Cabin`: Missing entries labeled as `"Unknown"`.
* **Data Validation:** Filters out invalid or out-of-range values (`Age > 0`, `Fare >= 0`, valid `Survived` flags `[0, 1]`, and valid `Pclass` tiers `[1, 2, 3]`).
* **Type Casting:** Converts `Pclass` to `category` and `Age` to `int64` for cleaner representation and memory efficiency.

### 2. Feature Engineering
* **`family_size`:** Combines `SibSp` (siblings/spouses) + `Parch` (parents/children) + `1` (the passenger) into a unified `family_size` metric, then drops the redundant `SibSp` and `Parch` columns.
* **Clean Export:** Resets the index and saves the processed dataset to `cleaned_titanic.csv`.

### 3. Exploratory Survival Analysis
The script outputs terminal summaries examining survival patterns across multiple dimensions:
* **Gender & Age Breakdown:** Total male vs. female survivors and average age comparison between survivors and non-survivors.
* **Port of Embarkation (`Embarked`):** Passenger counts, survivor counts, and survival percentages across **Southampton (`S`)**, **Cherbourg (`C`)**, and **Queenstown (`Q`)**.
* **Demographic Cohorts:** Compares survival rates across four distinct groups:
  * Children (`Age < 15`)
  * Elderly (`Age > 60`)
  * Middle-Aged Men (`Age 30–45`)
  * Middle-Aged Women (`Age 30–45`)
* **Family Dynamics:** Compares solo travelers (`family_size == 1`) against passengers traveling with family (`family_size > 1`), as well as small/average families (`<= 3`) vs. larger families (`> 3`).

* Python 3.8+

```bash
pip install pandas
```

### Running the Script
1. Clone this repository or download the files into the same directory.
2. Ensure `Titanic-Dataset.csv` is in the root folder alongside `pandasproject.py`.
3. Run the script from your terminal:
   ```bash
   python pandasproject.py
   ```
4. View the printed summary statistics in your console and find the exported `cleaned_titanic.csv` in the project directory.

## 📊 Key Analytical Takeaways
* **Women & Children Priority:** Middle-aged women (`30–45`) and children (`< 15`) recorded significantly higher survival rates than adult men (`30–45`) and elderly passengers (`> 60`).
* **Port Disparities:** Passengers embarking from **Cherbourg (`C`)** had the highest survival rate due to a higher concentration of first-class ticket holders.
* **Family Size Impact:** Passengers traveling in small family units (especially size `3`) survived at higher rates than solo travelers or large families (`> 3`).
